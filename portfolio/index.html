Projects

Best Paper Award, IEEE conference

Smart attendance system using PCA-based face recognition

A real-time face recognition system that takes attendance on a standard laptop, with no dedicated GPU.

  • Detects faces with Haar Cascade classifiers, then extracts high-dimensional facial features with Principal Component Analysis (PCA).
  • Compared SVM (RBF kernel) and Random Forest classifiers. SVM reached a peak target accuracy of 92%.
  • Added a blink-based liveness check so a printed photo can't pass as a person.

Methods: Haar Cascade, PCA, SVM (RBF), Random Forest

Business entity resolution challenge

A machine learning system that finds records describing the same business across several large data sources.

  • Generates match candidates at scale with exact and fuzzy blocking.
  • Builds similarity features with RapidFuzz and trains an XGBoost classifier tuned for precision.
  • Processes 15M+ business records with DuckDB, with the pipeline optimised to fit an 8 GB RAM environment.
  • Scores a 0.9757 macro F0.5 on the training candidate set.

Tools: DuckDB, RapidFuzz, XGBoost

Lead management: ML-based lead prioritisation

An end-to-end pipeline that ingests digital marketing leads and ranks them by how likely they are to convert.

  • Custom feature engineering modules track interaction recency, engagement frequency and session metrics.
  • Classification models (Logistic Regression and Random Forest) were trained, cross-validated and deployed.

Methods: Logistic Regression, Random Forest, cross-validation
